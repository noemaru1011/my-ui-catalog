# 角丸（ボーダー半径）

アプリケーション全体で使用する角丸ルールです。

通常の角丸は **10px** に統一し、CSS変数 `--radius` を基準として管理します。

角丸の値はCSS変数を通じて一元管理し、コンポーネントごとに異なる値を直接指定しないことを原則とします。

## 1. 基本ルール

通常のUIコンポーネントには、10pxの角丸を適用します。

基準値は `src/index.css` の `--radius` です。

```css
--radius: 0.625rem;
```

ルートの文字サイズが16pxの場合、10pxになります。

### Tailwind CSS

Tailwind CSSの角丸ユーティリティは、サイズ名にかかわらずすべて10pxになります。

| Tailwind クラス | CSS変数 | px |
| :--- | :---: | ---: |
| `rounded-sm` | `--radius-sm` | 10px |
| `rounded-md` | `--radius-md` | 10px |
| `rounded-lg` | `--radius-lg` | 10px |
| `rounded-xl` | `--radius-xl` | 10px |
| `rounded-2xl` | `--radius-2xl` | 10px |
| `rounded-3xl` | `--radius-3xl` | 10px |
| `rounded-4xl` | `--radius-4xl` | 10px |

### 角丸のプレビュー

各ユーティリティの角丸は同じ10pxです。

<div style={{ display: 'grid', gridTemplateColumns: 'repeat(auto-fill, minmax(130px, 1fr))', gap: '12px', color: 'var(--foreground)' }}>
  {[
    ['rounded-sm', '--radius-sm'],
    ['rounded-md', '--radius-md'],
    ['rounded-lg', '--radius-lg'],
    ['rounded-xl', '--radius-xl'],
    ['rounded-2xl', '--radius-2xl'],
    ['rounded-3xl', '--radius-3xl'],
    ['rounded-4xl', '--radius-4xl'],
  ].map(([name, variable]) => (
    <div key={name} style={{ border: '1px solid var(--border)', borderRadius: 'var(--radius)', padding: 12, background: 'var(--card)', color: 'var(--card-foreground)' }}>
      <div style={{ height: 64, background: 'var(--primary)', borderRadius: `var(${variable})`, opacity: 0.85 }} />
      <div style={{ fontWeight: 600, fontSize: 13, marginTop: 10 }}>{name}</div>
      <code style={{ display: 'block', fontSize: 11, color: 'var(--muted-foreground)', marginTop: 4 }}>{variable}</code>
      <div style={{ fontSize: 12, marginTop: 4 }}>10px</div>
    </div>
  ))}
</div>

### 適用範囲

以下のような通常のUIコンポーネントには、既存の `rounded-*` クラスを使用します。

- Button
- Input
- Card
- Dialog
- Select
- Popover

角丸を変更する場合は、個別のコンポーネントに数値を直接指定せず、`--radius` を変更してください。

### コンポーネントの継承

`elements` コンポーネントは、内部で使用する `ui` コンポーネントの角丸を引き継ぎます。

角丸を変更する場合は、利用側の `elements` コンポーネントに重ねて指定するのではなく、対応する `ui` コンポーネントを変更してください。

## 2. 例外

形状や表示上の理由がある場合は、10px以外の角丸を許容します。

### 例外一覧

| Tailwind クラス | 用途 | 理由 |
| :--- | :--- | :--- |
| `rounded-full` | 円形・カプセル形状 | 円形やつまみなどの形状を維持するため |
| `rounded-none` | 部品の接続・範囲選択 | 部品同士の連続性を表現するため |
| `rounded-[inherit]` | 親要素の内側 | 親要素の角丸を継承するため |
| `rounded-[2px]` | ツールチップの矢印 | 小さな装飾形状のため |

### 例外の使用例

#### `rounded-full`

円形やカプセル形状が必要な部品に使用します。

対象コンポーネント：

- `src/components/ui/radio-group.tsx`
- `src/components/ui/switch.tsx`
- `src/components/ui/drawer.tsx`（つまみ）

<div style={{ display: 'flex', alignItems: 'center', flexWrap: 'wrap', gap: 16, color: 'var(--foreground)' }}>
  <div style={{ width: 52, height: 52, borderRadius: '9999px', background: 'var(--primary)' }} />
  <div style={{ width: 100, height: 36, borderRadius: '9999px', background: 'var(--primary)' }} />
</div>

#### `rounded-none`

部品同士を繋げる場合や、範囲の連続性を表現する場合に使用します。

対象コンポーネント：

- `src/components/ui/input-group.tsx`（内側）
- `src/components/ui/calendar.tsx`（範囲選択）

#### `rounded-[inherit]`

親要素の角丸を子要素に引き継ぐ場合に使用します。

対象コンポーネント：

- `src/components/ui/drawer.tsx`（内部）

#### `rounded-[2px]`

小さな装飾形状に使用します。

対象コンポーネント：

- `src/components/ui/tooltip.tsx`（矢印）

## 3. カレンダーセルの角丸

カレンダーのセル角丸には、専用のCSS変数 `--cell-radius` を使用します。

```css
--cell-radius: var(--radius-md);
```

`--radius-md` は基本ルールに従い10pxとなります。

ただし、範囲選択中の角丸は、開始位置・終了位置・中間部分を正しく表現するため、個別に調整します。

### 範囲選択

- 開始位置：範囲の左端を丸める
- 中間部分：セル同士が連続するようにする
- 終了位置：範囲の右端を丸める

範囲選択の表示を優先し、必要な部分に限って個別の角丸指定を許容します。

## 4. 変更時の指針

角丸の追加・変更時には、以下のルールを確認してください。

### 開発時の確認事項

- 新しい通常部品には、10px以外の固定値を追加しない。
- 独自の角丸CSS変数を追加しない。
- 通常のUI部品には既存の `rounded-*` クラスを使用する。
- `rounded-full` は円形・カプセル形状が必要な場合に限って使用する。
- `rounded-none` は部品の接続や範囲の連続性が必要な場合に限って使用する。
- `rounded-[inherit]` は親要素の角丸を継承する必要がある場合に限って使用する。
- 例外の角丸を追加・変更した場合は、用途と理由を本ドキュメントにも反映する。

## 5. 設計原則

このプロジェクトでは、角丸をCSS変数で一元管理し、UI全体の一貫性を維持します。

| 項目 | ルール |
| :--- | :--- |
| 標準の角丸 | 10px |
| 基準の変数 | `--radius` |
| Tailwindクラス | `rounded-sm` ～ `rounded-4xl` |
| 変更方法 | CSS変数 `--radius` を変更 |
| 例外 | 形状・表示上の理由がある場合のみ許容 |

**基本原則：通常の角丸は10pxに統一し、例外は明確な用途と理由がある場合に限って使用する。**
