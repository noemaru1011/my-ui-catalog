# Color System

アプリケーション全体で使用するカラートークンの一覧です。

カラーはCSS変数で管理し、コンポーネントから直接参照します。

## 1. Primitive Colors

ブランドカラーや基本色のスケールです。

### Blue

ブランドカラー

<div style={{ display: 'grid', gridTemplateColumns: 'repeat(auto-fill, minmax(130px, 1fr))', gap: '12px' }}>
  {Array.from({ length: 13 }, (_, i) => {
    const value = i === 0 ? 50 : i * 100;
    const variable = `--color-blue-${value}`;

    return (
      <div key={variable} style={{ border: '1px solid var(--border)', borderRadius: 8, overflow: 'hidden' }}>
        <div style={{ height: 64, backgroundColor: `var(${variable})`, borderBottom: '1px solid var(--border)' }} />
        <div style={{ padding: 10 }}>
          <div style={{ fontWeight: 600, fontSize: 13 }}>Blue {value}</div>
          <code style={{ display: 'block', marginTop: 4, fontSize: 11, color: 'var(--muted-foreground)', overflowWrap: 'anywhere' }}>{variable}</code>
        </div>
      </div>
    );
  })}
</div>

## 7. Light / Dark Theme

LightとDarkでは同じセマンティック変数を使用します。

- Light: `:root` に定義された値
- Dark: `.dark` に定義された値

テーマによってCSS変数の値が切り替わります。
