# Layer

影と重なり順のルールです。

影は要素の浮き具合を表し、`z-index` は要素同士の前後関係を決めます。役割ごとに共通トークンを使い、`elements` 側で個別に上書きせず、基本は利用する `ui` コンポーネントに任せます。

## 1. Shadow

| Tailwind クラス | 基準 | 用途 |
| :--- | :--- | :--- |
| 影なし | なし | 通常のカードや入力欄。境界は枠線や `ring` で表現 |
| `shadow-popover` | `shadow-md` | メニューやポップアップ |
| `shadow-toast` | `shadow-lg` | 通知 |

`shadow-popover` と `shadow-toast` は `src/index.css` で定義しています。

カードやダイアログなどに影を追加する場合は、まず既存の枠線や背景で十分か確認します。（基本的には追加しない方針）

<div style={{ display: 'grid', gridTemplateColumns: 'repeat(auto-fill, minmax(160px, 1fr))', gap: 16 }}>
  {[
    { name: 'No Shadow', description: '影なし', shadow: 'none' },
    { name: 'Popover', description: 'shadow-md', shadow: 'var(--shadow-md)' },

    <div key={item.name}>
      <div style={{ height: 90, display: 'flex', alignItems: 'center', justifyContent: 'center', background: 'var(--card)', border: '1px solid var(--border)', borderRadius: 10, boxShadow: item.shadow }}>

      </div>
      <div style={{ fontSize: 12, color: 'var(--muted-foreground)', marginTop: 8 }}>{item.description}</div>
    </div>
  ))}
</div>

## 2. Z-Index

| Tailwind クラス | 値 | 用途 |
| :--- | ---: | :--- |
| `z-base` | 0 | 基準面 |
| `z-local` | 10 | コンポーネント内部の部品の重なり |
| `z-sticky` | 10 | 固定ヘッダーなど |
| `z-overlay` | 40 | Dialog などの背景オーバーレイ |
| `z-modal` | 50 | Dialog、AlertDialog、Drawer 本体 |
| `z-popover` | 60 | メニューやポップアップ。Dialog 内でも前面に表示 |
| `z-toast` | 70 | 通知領域 |
| `z-tooltip` | 80 | Tooltip |

値は `src/index.css` の `--z-index-*` 変数で管理します。

`z-index` はスタッキングコンテキストごとに比較されるため、値を増やすだけでは解決しない場合があります。

### Z-Index Preview

<div style={{ display: 'flex', flexDirection: 'column', gap: 8 }}>
  {[
    ['z-base', 0],
    ['z-local', 10],
    ['z-sticky', 10],
    ['z-overlay', 40],
    ['z-modal', 50],
    ['z-popover', 60],
    ['z-toast', 70],
    ['z-tooltip', 80],
  ].map(([name, value]) => (
    <div key={name} style={{ display: 'grid', gridTemplateColumns: '130px 1fr 32px', alignItems: 'center', gap: 10 }}>
      <code style={{ fontSize: 12 }}>{name}</code>
      <div style={{ height: 12, background: 'var(--muted)', borderRadius: 6, overflow: 'hidden' }}>
        <div style={{ width: `${Math.max(Number(value), 4) / 80 * 100}%`, height: '100%', background: 'var(--primary)', borderRadius: 6 }} />
      </div>
      <span style={{ fontSize: 12, textAlign: 'right' }}>{value}</span>
    </div>
  ))}
</div>


Toast の各カードは、通知同士の順序を制御するため `--toast-index` を使った動的な `z-index` を持ちます。これは `z-toast` の通知レイヤー内での例外です。
