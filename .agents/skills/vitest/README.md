# Vitest

Reference material for Vitest configuration, test APIs, mocking, browser and
other environments, coverage, filtering, and related features.

Use this skill when writing or debugging Vitest tests, configuring the runner,
or looking up test utilities. The project uses Vitest with browser-mode
Playwright for component tests.

See [SKILL.md](./SKILL.md) for the topic index and
[references/](./references) for detailed guides.
