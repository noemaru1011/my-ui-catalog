# Props-Based UI Unit Tests

Guidance for creating and reviewing unit tests for props-driven React UI
components using Vitest and React Testing Library.

Use this skill to test rendering, user interactions, callbacks, accessibility,
validation, disabled and read-only states, fixtures, and edge cases. Tests
should focus on observable behavior and follow the project's existing test
conventions.

See [SKILL.md](./SKILL.md) for the full workflow and project-specific fixture
guidance.
