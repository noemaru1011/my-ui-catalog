# TanStack Data Tables

Guidance for building data tables in this project with TanStack Table v9,
including feature registration, typed columns, table state, row actions, and
the project's example file structure.

Use this skill when creating, refactoring, or debugging a data table.

See [SKILL.md](./SKILL.md) for the full guidance and
[table-architecture.md](./references/table-architecture.md) for the project
structure and implementation checklist.
