# Skills Index

This directory contains specialized skills used for development workflows and project-specific tasks.

Read the relevant `SKILL.md` before performing tasks covered by these skills. Refer to additional documentation in each skill's `references/` directory when necessary.

## Available Skills

### gh

**Path:** `gh/SKILL.md`

GitHub CLI workflows.

Use when:

- Managing GitHub repositories, issues, and pull requests.
- Working with GitHub through the `gh` CLI.
- Reviewing or managing repository-related tasks.

### playwright-cli

**Path:** `playwright-cli/SKILL.md`

Browser automation and Playwright CLI workflows.

Use when:

- Automating browser interactions.
- Inspecting and debugging web applications.
- Generating or running browser tests.
- Managing browser sessions, authentication, and storage state.
- Capturing screenshots, videos, and traces.

Additional documentation is available in `playwright-cli/references/`.

### shadcn-ui-comment-history

**Path:** `shadcn-ui-comment-history/SKILL.md`

shadcn/ui component implementation and customization guidance.

Use when:

- Implementing or customizing shadcn/ui components.
- Reviewing component-related implementation decisions.
- Referring to historical implementation notes and comments.

Additional documentation is available in `shadcn-ui-comment-history/README.md`.

### vitest

**Path:** `vitest/SKILL.md`

Vitest testing framework documentation and workflows.

Use when:

- Writing or maintaining unit and integration tests.
- Configuring Vitest.
- Implementing mocks, assertions, and test hooks.
- Working with coverage, snapshots, or test environments.
- Performing type testing or advanced test configuration.

Additional documentation is available in `vitest/references/`.

## Guidelines

- Read the relevant skill before starting a task that falls within its scope.
- Consult reference files when the main skill documentation points to them or when additional details are needed.
- Apply project conventions documented in `AGENTS.md` alongside the relevant skill instructions.
- Avoid loading unrelated skills or reference files.
