## 2. テーマカラーの用途定義

ライトモードとダークモードで、同じ用途に対して異なるカラーを割り当てる。

### 2.1 基本カラー

| 用途         | ライトモード          | ダークモード         |
| ------------ | --------------------- | -------------------- |
| プライマリー | Blue-900 (`#0017C1`)  | Blue-300 (`#9DB7F9`) |
| セカンダリー | Blue-700 (`#264AF4`)  | Blue-500 (`#4979F5`) |
| ターシャリ   | Blue-1000 (`#00118F`) | `#8FB8FF`            |
| 背景色       | Blue-50 (`#E8F1FE`)   | `oklch(0.145 0 0)`   |
| 文字色       | `oklch(0.145 0 0)`    | `oklch(0.985 0 0)`   |

### 2.2 リンクカラー

リンクの状態に応じて、ライトモードとダークモードでカラーを切り替える。

| 状態    | ライトモード            | ダークモード            |
| ------- | ----------------------- | ----------------------- |
| Default | Blue-1000 (`#00118F`)   | `#8FB8FF`               |
| Visited | Magenta-900 (`#8B008B`) | Magenta-200 (`#FFAEFF`) |

### 2.3 フォーカスカラー

| 種別    | ライトモード           | ダークモード           |
| ------- | ---------------------- | ---------------------- |
| Focus-1 | Yellow-300 (`#FFD43D`) | Yellow-300 (`#FFD43D`) |
| Focus-2 | Black (`#000000`)      | Black (`#000000`)      |

### 2.4 検索ハイライトカラー

## 7. テーマ切り替えルール

### 7.1 ライトモード

- ライトモードは標準テーマとする。
- 背景色にはBlue-50を使用する。
- 文字色には濃色を使用し、視認性を確保する。
- プライマリーカラーにはBlue-900を使用する。
- リンクやボタンなどのインタラクティブ要素には、Blue系の濃色を使用する。

### 7.2 ダークモード

- ダークモードでは背景色に暗色を使用する。
- 文字色には明色を使用し、背景とのコントラストを確保する。
- プライマリーカラーにはBlue-300を使用する。
- リンクやボタンなどのインタラクティブ要素には、Blue系の明色を使用する。
- 検索ハイライトは背景色と境界線の色を反転させる。
- CardやPopoverなどのコンポーネントもダークモード用の背景色・文字色に切り替える。
- Success / Error / Warningは、原則として共通の機能カラーを使用する。

### 7.3 テーマ切り替え方式

- ライトモードでは`:root`に定義したCSS変数を使用する。
- ダークモードでは`.dark`に定義したCSS変数を使用する。
- テーマ切り替え時は、CSS変数の値を変更することで各UIコンポーネントに反映する。
- コンポーネント側ではプリミティブカラーの直接指定を避け、セマンティックカラーを参照する。

## 8. 補足事項

- Blue-50 ～ Blue-1200はBlue系プリミティブカラーとして定義する。
- その他のプリミティブカラーも共通定義とし、ライトモード・ダークモードの両方から参照する。
- 各用途では、プリミティブカラーまたはセマンティックカラーを参照して使用する。
- ライトモードとダークモードで用途が同じ場合でも、視認性を考慮して異なるカラーを割り当てる場合がある。
- Success / Error / Warningは、状態や意味を表現する機能カラーとして使用する。
- ボタンはDefault / Hover / Activeの状態に応じて背景色を切り替える。
- リンクはDefault / Visitedの状態に応じて色を切り替える。
- コンポーネントの背景色や文字色には、可能な限りセマンティックカラーを使用する。
- 色の変更はCSS変数で一元管理し、コンポーネント単位で個別に色を定義しない。
