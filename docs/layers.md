# 影と重なり順のルール

影は要素の浮き具合を表し、`z-index` は要素同士の前後関係を決めます。役割ごとに共通トークンを使い、`elements` 側で個別に上書きせず、基本は利用する `ui` コンポーネントに任せます。

## 影

| Tailwind クラス  | 基準        | 用途                                             |
| ---------------- | ----------- | ------------------------------------------------ |
| 影なし           | なし        | 通常のカードや入力欄。境界は枠線や `ring` で表現 |
| `shadow-popover` | `shadow-md` | メニューやポップアップ                           |
| `shadow-toast`   | `shadow-lg` | 通知                                             |

`shadow-popover` と `shadow-toast` は [index.css](../src/index.css) で定義しています。カードやダイアログなどに影を追加する場合は、まず既存の枠線や背景で十分か確認します。

## 重なり順

| Tailwind クラス |  値 | 用途                                            |
| --------------- | --: | ----------------------------------------------- |
| `z-base`        |   0 | 基準面                                          |
| `z-local`       |  10 | コンポーネント内部の部品の重なり                |
| `z-sticky`      |  10 | 固定ヘッダーなど                                |
| `z-overlay`     |  40 | Dialog などの背景オーバーレイ                   |
| `z-modal`       |  50 | Dialog、AlertDialog、Drawer 本体                |
| `z-popover`     |  60 | メニューやポップアップ。Dialog 内でも前面に表示 |
| `z-toast`       |  70 | 通知領域                                        |
| `z-tooltip`     |  80 | Tooltip                                         |

値は [index.css](../src/index.css) の `--z-index-*` 変数で管理します。`z-index` はスタッキングコンテキストごとに比較されるため、値を増やすだけでは解決しない場合があります。

Toast の各カードは、通知同士の順序を制御するため `--toast-index` を使った動的な `z-index` を持ちます。これは `z-toast` の通知レイヤー内での例外です。

## 変更時の確認

- 影と重なり順を `elements` 側で重複指定せず、共通の `ui` コンポーネントとトークンで揃えます。
- 新しい影やレイヤーが必要な場合は、用途を決めて [index.css](../src/index.css) とこの表を一緒に更新します。
- Dialog や Drawer の上にポップアップを開く組み合わせなど、重なりが入れ子になる操作も確認します。
